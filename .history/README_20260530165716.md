# ✨ Magical Hand by Mamifa

> Une plateforme moderne de réservation de services de maquillage, conçue pour offrir une expérience fluide, élégante et professionnelle.

**Application Full-Stack · React · Firebase · Déploiement Vercel**

---

## 📌 Présentation du projet

**Magical Hand by Mamifa** est une application web développée pour une maquilleuse professionnelle afin de :

* Présenter ses prestations et son travail
* Gérer les réservations clients
* Afficher les disponibilités en temps réel
* Centraliser les demandes via WhatsApp
* Offrir une expérience utilisateur moderne et responsive

Ce projet simule un **système SaaS de réservation réel**, adapté au domaine de la beauté.

## 🔥 Configuration Firebase

L’application utilise Firebase pour :

* L’authentification des administrateurs
* La base de données (Firestore)
* Le stockage des images

Étapes :

1. Créer un projet Firebase
2. Activer l’authentification Email/Mot de passe
3. Créer Firestore Database
4. Activer Storage
5. Ajouter la configuration dans `src/firebase.js`
